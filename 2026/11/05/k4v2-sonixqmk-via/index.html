SonixQMK/VIA Firmware on Keychron K4 V2 RGB

Posted on 2026-11-04

Build and install SonixQMK/VIA on keychron k4v2. RGB model ONLY, not for white backlight.

All the files are available at https://github.com/lexr1/k4v2-sonixqmk-via/

Install QMK MSYS

I use latest stable release 1.12.

https://github.com/qmk/qmk_distro_msys/releases#release-1.12.0

No need to select "Install drivers"

Build

Get SonixQMK, add VIA keymap and build. Thanks to the developers, it's a straightforward process and everything compiles cleanly.

Open QMK MSYS console and run:

The firmware is in D:\work\sonixqmk\keychron_k4_rgb_v2_ansi(iso)_via.bin

Flash

Get the SonixQMK flasher(depreciated but works fine, or get the command line one)

https://github.com/SonixQMK/sonix-flasher/releases

Then

  1. Put the keyboard to wired mode
  2. Unplug the USB cable.
  3. Remove the space bar and short the 2 boot pins.
  4. Keep the pins shorted, plug the USB cable and now unshort the 2 pins.
  5. Run the flasher and check.

If everything looks good, click "Flash QMK...", select the firmware and flash.

Config the keyboard

Open https://www.usevia.app/ goto "Settings", enable "Show Design tab". At Design tab, select "Load draft Definition" and load the json file.

This firmware uses RGB_MATRIX for backlight and full keycode list is on https://docs.qmk.fm/keycodes

Bootloader mode and back to stock

In VIA, the Fn+ESC is assigned to RESET which will put the keyboard to bootloader mode without shorting the boot pins.

To back to stock, boot to bootloader mode and run the official firmware(K4 V2 Gateron RGB Backlight V1.07).

To exit bootloader mode, either unplug/plug the USB cable, or use the side switch to power cycle the keyboard.
